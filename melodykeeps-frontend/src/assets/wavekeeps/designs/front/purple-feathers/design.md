# Classic White Front Design

> STATUS: REFERENCE  
> PURPOSE: Verified functional front design for WaveKeeps

Reference design for the classic white music player front.

Composition:
- Verified player (immutable geometry per 02-PLAYER-CONTRACT.md)
- Decorative overlay: flow lines, sparkles, micro-accents
- Feathers placement: 13 positions (see manifest)

Asset organization:
```
assets/
├── feathers/       PNG raster assets (transparent)
├── flow-lines/     SVG and/or PNG decorative curves
├── micro-accents/  SVG dots and geometry
└── sparkles/       SVG circles
```

See `manifest.json` for placement coordinates.

See `../../03-DESIGN-METHOD.md` for production rules.
