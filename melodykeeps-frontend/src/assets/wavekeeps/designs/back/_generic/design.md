# Generic Back Design

> STATUS: FALLBACK  
> PURPOSE: Default back when song-specific back unavailable

Generic back used when a song does not have an approved song-specific back design.

Required content zones (must not overlap):
- QR code
- CTA ("ESCANEA Y ESCUCHA")
- Quote
- Song / Artist identity

See `manifest.json` for zone placement.

See `../../03-DESIGN-METHOD.md` for production rules.
